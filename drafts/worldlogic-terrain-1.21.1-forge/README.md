# WorldLogic: Terrain — visual prototype

Target: Minecraft 1.21.1 / Forge 52.1.0 / Java 21 / official mappings. Current WorldLogic source rc19; provided binary rc17. Visual assets only, deliberately outside projects/ and not enrolled in Build Hub. No Java, registrations, worldgen or release JAR yet.

18 plant/ground-cover types, 20 original 16x16 textures and corresponding models. Cutout cross planes for grasses/flowers, three planes for dense shrubs, horizontal planes for litter; reed and cattail have separate upper and lower models. Vanilla 1.21.1 short grass, fern and poppy used as reference, not redistributed.

Next: test in a graphical client, check double-plant seams; ground cover needs random 90-degree rotations/variants to avoid a visible repetitive pattern (3x3 preview currently shows repetition). Registration and biome distribution deferred. No runtime or release QA claimed.
