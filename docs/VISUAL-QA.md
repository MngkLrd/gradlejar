# Fast Visual QA v1

The [Blockbench Minecraft Style Guide](https://blockbench.net/wiki/guides/minecraft-style-guide/) is the style authority; see AGENTS.md. Visual QA measures rather than judges art. No universal color/cluster quotas. Analyze changed assets only, without Gradle or Minecraft startup. A separate GitHub Actions job runs automatically on asset/tool changes, independent of Build Hub. It does not impose a new automatic release gate or mutate existing textures. Existing JAR asset gate remains active.

- Item/block/entity PNG: exact four-neighbor connected RGB clusters (ignore fully transparent pixels), isolated/small cluster fractions, palette count, equal-color neighbor fraction, adjacent HSV steps, partial alpha and alternating 2x2 patterns. Metrics and heuristic warnings are not aesthetic grades. Animated atlases/metadata are identified; frame-level style warnings and tiling omitted.
- Models: element counts, subpixel geometry and estimated unequal UV texel density for explicit JSON faces with resolvable local textures. Not inherited models, runtime/Blockbench meshes, material semantics or exact geometry certification.
- Real vanilla reference: selected item/block/entity textures from official 1.21.1 client, metadata and client SHA-1 verified, cached metrics only. Matching category/size ranges are contextual examples, not acceptance thresholds; choose comparable material references during design. No redistribution of vanilla PNGs.
- Previews: native PNG, nearest-neighbor enlargement and 3x3 block tile for up to 32 unique textures. Review tiling visually. Transparent materials, thin elements, dithering and nonstandard sizes can be intentional.
- Structural errors: unreadable PNG, malformed model JSON, invalid explicit UV are job failures. Heuristic style warnings are advisory. Review and correct actual defects; default one redraw iteration, not an automatic numeric-score optimization. Full graphical gameplay validation and bot screenshot comparison are not implemented; protocol bot has no renderer.
- Run locally on changed assets: `python -m pip install Pillow==12.0.0`, `python -m tools.qa.visual_lint --paths path/to/texture.png path/to/model.json --out visual-qa`. Inspect final JAR if needed: `python -m tools.qa.visual_lint --jar build/libs/mod.jar --out visual-qa`. Generate reference with `python -m tools.qa.visual_lint --make-vanilla-reference 1.21.1 --out visual-reference.json` and pass `--reference visual-reference.json`.
- Report and previews are retained as MineMods-Visual-QA artifact. Avoid running client per asset or heavy tests for a cosmetic change. CI reports measurements, not guaranteed runtime rendering or style compliance. Agents must still follow the guide.
