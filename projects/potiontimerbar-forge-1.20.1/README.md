# Potion Timer Bar 0.3.1 - forge 1.20.1

Client HUD: one 81x5 pixel potion-colored countdown bar. Selects longest remaining active effect. Potion registry palette with harmful red and beneficial light green fallbacks. No status effect means no bar. Config: config/potiontimerbar-client.toml. Java 17, Gradle 8.14.5. No additional dependencies. Build: gradle clean build. Release JAR: build/libs/potiontimerbar-forge-mc1.20.1-0.3.1.jar.
