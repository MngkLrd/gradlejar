# Fragile Glass 1.0.2
Minecraft 26.2 / neoforge / Java 25 / Gradle 9.2.1.
Build: gradle clean build. Output: build/libs/fragileglass-neoforge-mc26.2-1.0.2.jar.
Vanilla glass, panes, colored and tinted variants recognized by exact vanilla ID without reliance on data tags; optional tags still extend or exclude blocks. Fabric Loader alone does not guarantee discovery of embedded server data packs, so use external data packs or a compatible resource-loader API for custom tags. No mandatory Fabric API dependency. CI runs a real dedicated server and checks impacts, hard falls and unaffected controls. Manual client testing remains necessary.
