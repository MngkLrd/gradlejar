# Bearback 0.2.2 for Fabric 26.2
Native Fabric port of black and polar bear taming, riding, combat, 3D saddles and leather cargo bags (18 slots).
Preserves version-correct 26.2 shaped recipe with string ingredient IDs and result id.
Java 25, build with Gradle 9.5.1: `gradle clean build`. JAR in build/libs.
