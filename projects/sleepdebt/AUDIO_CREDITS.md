# Sleepless audio provenance (3.0.0-alpha.12)

The following audio recordings are **CC0 1.0** (public domain dedication).
They are downloaded at build time from a pinned, publicly available GitHub
mirror and re-encoded as mono 24 kHz Vorbis OGG for Minecraft. The original
MP3 files are **not** shipped in the JAR.

- `breath.ogg`: "Creature breathing" by 999999990,
  https://freesound.org/people/999999990/sounds/320345/
- `whisper.ogg`: "Creepy whispers" by dimbark1,
  https://freesound.org/people/dimbark1/sounds/316797/
- `growl.ogg`: "Monster growl" by JoelAudio,
  https://freesound.org/people/JoelAudio/sounds/85568/
- `strike.ogg`: "Choking" by Breviceps,
  https://freesound.org/people/Breviceps/sounds/444723/

CC0 records verified against the source table in
https://github.com/mayerwin/halloween-soundboard (README asset licenses).
The build pins revision `ba116cae4ef9f479c3a8e0bd50ebf6ada36cedf8`
and checks each source's Git blob SHA-1 before encoding.

- `heartbeat.ogg`: original programmatically synthesized percussion for Sleep Debt.
  No third-party recordings used.

These recordings are not taken from Minecraft. The model/skin texture,
world fog and animations are also original. The GitHub mirror and the original
Freesound creators do not endorse Sleep Debt.
