# WorldLogic Excavation 0.2.1 — candidate API
Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21. Required Core 1.5.0 (candidate PR #262, e69ac212). Discover `WorldLogicCapabilities.find(ExcavationApi.KEY,0)` (v1 rev1). Server thread only, loaded block only; absent for unsupported blocks or invalid saved proxy. Snapshot gives source ID, exact work (0..179 of 180), six 4-bit face depths (DOWN UP NORTH SOUTH WEST EAST), remaining mineral units (0 for rock), latest known incident J/m² or NaN. `strike(ServerPlayer,BlockPos)` validates game mode, live aim, reach, permissions, loaded chunk, tool suitability and cooldown; authoritative entrypoint shared by network and QA. Result reports accepted/broken/rejected and emitted mineral units; no mutable raw state.

Core owns physical composition/contact and tool suitability. First hit uses typed `WorldLogicExcavation.inspect`; proxy uses its original registered block for hardness and correct-tool checks until the state-aware overload requested in issue #264 exists. Incident energy is telemetry using an explicit 0.00015 m² contact, 4 m/s swing and actual known tool mass capped at 3 kg; not a fracture limit. No second fatigue pool. Intermediate claim checks post one scoped BreakEvent and currently Core charges that event; final normal gameMode.destroyBlock accounts for final hit. No duplicate manual debit. Core arbitration/production JAR requested in #264.

Gameplay reserve: one natural ore block contains nine units; small 1, medium 4, large 9. Metal smelting yields 1/4 nuggets or one ingot. Copper nugget is addon-owned since 1.21.1 has no vanilla copper nugget. Nonmetal/minerals without established metal products combine to large then retain the vanilla/Core material product; ancient debris smelts to scrap. Stone gives exactly one final cobblestone (deepslate cobbled deepslate); other raw rocks retain one original block. No small stone drops or TreeChopper runtime dependency. Fixed reserve does not apply Fortune/Silk Touch. Destroying a partly chipped block through explosions/commands yields no additional ore (unextracted reserve is lost). Vanilla unmodified ores outside the addon strike path keep their existing explosion loot. No XP from fractional mining, smelting provides XP. Compact soil digging is included; falling sand/gravel and farmland are deliberately excluded to preserve their native physics and crop state.

Real voxel notches retain six independent depths in one chunk-persisted block entity per touched block. Original source-specific proxy block has no item or loot, with model and collision generated from one 16px voxel solid. Bounded geometry, shape and per-material baked caches; no ticking rock entities or chunk-wide scanning. Core ore patches use existing mineral sprite; no copied PNGs. Core's original protruding ore model and orientation variants are not exactly preserved in chipped geometry. Graphical evidence pending.

Evidence: source draft, actual Build Hub and same-commit compatibility pack must be run, exact Core candidate required. FakePlayer server QA path tests real validation, break, item yield and durability; no claim of network or graphical execution. Persistence reload, cross-mod protections, recipe execution and exact Core effort arbitration still need runtime evidence. See #264.

Manifest capability `worldlogic:rock_fracture` maps to the typed runtime key `worldlogicexcavation:fracture` (provider namespace required by Core 1.5.0). Consumers use `ExcavationApi.KEY`.

## Revision 1: time correlation and soil
`timing(player,pos)` reports vanilla duration from original BlockState.getDestroyProgress (effective player speed including vanilla enchantments/status/attributes), target ticks floor(1.5× vanilla) for rock/soil or 2× for ore, and a feasible hit count. For constant tool/status the first accepted click is immediate; remaining gaps partition the integer target exactly. Gaps are at least four ticks; near-instant blocks reduce the number of required clicks to one. One-click mining is faster than the target, not a delayed fake notch. Slow human clicking, network latency or changing tool/status can extend real elapsed time; the mod never imposes a longer fixed-tool schedule than 2× vanilla. The previous accepted hit's cadence survives target/tool changes until its next eligible tick; completion permits the next block after one tick. Native dirt/grass/coarse/rooted/podzol/mycelium/mud/clay and eight Core compact soils use the same six-face geometry and the shovel role; hands remain viable. Original soil loot is emitted only after final normal break. No new soil items or textures; grass top uses biome tint, side overlay not yet recreated. Falling sand/gravel, farmland and path blocks retain vanilla mechanics. Exact Core intermediate exertion arbitration and joint runtime still pending. Standalone math verification uses dedicated Gradle verification source set, not JUnit discovery.
