# WorldLogic Terrain 0.3.0
Minecraft 1.21.1, NeoForge, Java 21, Gradle 9.2.1, official mappings. Requires WorldLogic RC20+ API v1. Build verifies pinned RC20 JAR; no shaded core. Runtime QA installs the same dependency. Metadata minimum 21.1.80, QA pin 21.1.262.
18 plants, 20 textures/models, block items, loot, RU/EN and natural tab. Surface and vegetation movement uses core API as before.
Worldgen: 18 separate configured and placed random-patch features, 12 editable biome tags, NeoForge add_features at vegetal_decoration. All WorldLogic presets use the standard overworld multi_noise biome source and their own noise settings. No overwriting core presets, no new dimensions, no forced chunk loading/retrogen. Features also run in vanilla overworld biomes if the core is installed; biome modifiers deliberately act at the shared decoration layer. Existing chunks do not regenerate. Tall wetland plants support mud/clay. Plant distribution is biome/ground based, not direct climate API access (server API is not safe on worldgen threads).
QA: server verifies actual modified biome decoration lists for all 3 registered core generators, runs all 18 configured features on real substrate fixtures, and rejects invalid stone. The shared QA runner starts a flat world; these checks are not a full custom-world generated-chunk survey. Client and actual network-player movement remain unverified. No new trees.
Build: gradle --no-daemon clean build. Output build/libs/worldlogicterrain-neoforge-mc1.21.1-0.3.0.jar.
