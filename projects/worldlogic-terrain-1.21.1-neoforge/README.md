# WorldLogic Terrain 0.6.0
Minecraft 1.21.1, NeoForge, Java 21, Gradle 9.2.1, official mappings. Requires WorldLogic RC20+ API v1. Build verifies pinned RC20 JAR; no shaded core. Runtime QA installs the same dependency. Metadata minimum 21.1.80, QA pin 21.1.262.
32 plants, 46 textures (20 old + 26 new), 12 new edible items, block items, loot, RU/EN and natural tab. Surface and vegetation movement uses core API as before.
Worldgen: 32 separate configured and placed random-patch features, 22 editable biome tags, NeoForge add_features at vegetal_decoration. All WorldLogic presets use the standard overworld multi_noise biome source and their own noise settings. No overwriting core presets, no new dimensions, no forced chunk loading/retrogen. Features also run in vanilla overworld biomes if the core is installed; biome modifiers deliberately act at the shared decoration layer. Existing chunks do not regenerate. Tall wetland plants support mud/clay. Plant distribution is biome/ground based, not direct climate API access (server API is not safe on worldgen threads).
QA: server verifies actual modified biome decoration lists for all 3 registered core generators, runs all 32 configured features on real substrate fixtures, and rejects invalid stone. The shared QA runner starts a flat world; these checks are not a full custom-world generated-chunk survey. Client and actual network-player movement remain unverified. No new trees.
Build: gradle --no-daemon clean build. Output build/libs/worldlogicterrain-neoforge-mc1.21.1-0.6.0.jar.

Additional product-only worldgen QA: qa-worldlogicterrain-worldgen.yml retrieves the eligible Build Hub artifact for the exact same commit, verifies its SHA-256, starts a fresh Earthlike Climate server and scans actual full Anvil chunk palettes and packed block-state indices. All five reported biome types are attempted; unlocatable biomes are explicitly NOT_FOUND, never PASS. This is complementary evidence, not a bypass of the shared gate.

0.4.0 forage: 12 wild edible plant blocks, 12 food items, bracken and marsh marigold. Harvest by breaking, one food per edible plant, no seeds, farming, regeneration, fruit trees or recipes. Food hunger 2–5 and varied vanilla saturation; strawberry, blueberry, raspberry, grape and pineapple recover 2–6 core exertion units through WorldLogicApi, only during normal eating. No separate stamina or nutrition system. Food QA uses actual loot tables, item finishUsingItem, FakePlayer food state and core fatigue, not network clicks. Original 16x16 cutout sprites, no borrowed assets. Client visuals unverified. Natural-world QA additionally requires new forage vegetation in four suitable biomes.

0.5.0: 34 existing block sprites revised, 5 unripe models/textures, no new species. Ground cover, shrubs and edible patches now use rarity filters 1/2–1/6 instead of per-chunk count 1–2. Grass is a distinct 33rd placed feature: vanilla short grass only in air above grass_block, 3 patch attempts, 32 tries, no replacement of existing blocks. Berry/grape right-click yields one food and changes persistent ripe flag; unripe produces no further berries until a random tick with light >=9 and probability 1/5. Old IDs preserved; old unversioned berry states default ripe. No fruit tree or core generator changes. QA extends existing FakePlayer food assertions to right-click server method, actual spawned loot, duplicate prevention, unripe loot and deterministic random tick regrowth, and checks grass substrate and natural column density (<=18% addon-covered columns in sampled 5x5 chunk windows and more vanilla short grass than addon columns on plains). Existing generated chunks unchanged. Client renderer and physical input remain unverified.

0.6.0: 33 species, 35 placed features (including vanilla grass and mixed meadow), compact radius 3 blocks for all species patches, same forest/shrub/berry frequencies. One new weighted mixed meadow patch per eligible open-biome chunk; only replaces vanilla short grass or air above real soil, not tall plants, blocks or existing player builds. Mixed meadow patches contain meadow grass, dense grass, clover and flowers. Dry grass frequencies 1/2 and 1/3 on deserts/savannas/badlands and beach. Native frosted grass sprite, block and item, generated in snowy biomes on suitable soil, not solid ice or snow blocks. Extra green short grass injection removed from snowy biomes. New server test uses real configured features, confirms mixed species, compact radius, grass outside unchanged, frost generation, negative substrate, support and actual loot. No retrogen, no change to core, no tree generation changes. Existing worlds need new chunks. Client graphics unverified.

0.6.0 natural-world regression keeps the previous 18% maximum add-on column coverage, adds snowy_plains to the six attempted locations, and requires the fixed-seed plains sample to exceed the 0.5.0 baseline (at least 70 meadow species blocks vs 51), at least two connected groups of 4+ meadow columns, and at least four 8x8 cells with ordinary grass but no add-on vegetation. This is measured in stored Anvil chunks, not predicted from placement parameters. Unlocated biomes remain explicitly NOT_FOUND, not passed.
