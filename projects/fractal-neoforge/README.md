# FRACTAL 0.2.0
Minecraft 1.21.1 / NeoForge 21.1.228 / Java 21 / Gradle 9.2.1. Standalone. Experimental.
Use /give @s fractal:matter_probe and /give @s fractal:lattice_lens. Enter stone, copper block or vertical oak log with the probe. Six sockets accept offhand iron, redstone or glowstone. Place a supported block DIRECTLY ON TOP of a socket, enter that child and modify it: each child contributes half its effective properties, rounded up, to the parent, capped at three per property. Coupling propagates through up to three levels. Remove a child to remove its contribution. The visible cutaway is a 7x7x3 coarse snapshot of the actual chamber, refreshed from loaded cells; it favors player-built blocks and functional nodes over the shell. Right-click host with Matter Lens to toggle the cutaway. Host retains full-block collision. The preview is a block entity renderer, not a second live camera; no animation of entities, no detailed block states, no arbitrary physical scale. Nearby host/occupied lineage receive temporary chunk tickets; no permanent forced chunks. Outside west input/east output. Inside input terminal west and output terminal east. Shift-click probe on host to inspect; /fractal ascend to leave. Fresh test world recommended. Old v0.1 cells keep the same SavedData key; migration is untested. Runtime test pending.
