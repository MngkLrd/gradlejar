# FRACTAL 0.1.0
Minecraft 1.21.1 / NeoForge 21.1.228+ / Java 21. Standalone. Playable technical alpha of nested material editing, not a seamless spatial engine.
Give yourself /give @s fractal:matter_probe. Right-click stone, copper block or vertical oak log to convert it into its own persistent material cell and descend. Right-click a live cell again to enter it. Shift-click a host to inspect. Six lattice sockets inside accept an iron ingot (reinforcement), redstone dust (conductivity) or glowstone dust (light) in the offhand while using the probe; shift-use with empty offhand clears a socket, no refund. Each property caps at 3 nodes; external light is 5/10/15; mining speed is scaled by 1/(1+.75R). Copper begins with two conductors, stone with one reinforcement, wood neutral. External host WEST receives signal; EAST outputs signal. Inside input terminal on west is a signal source; output terminal east senses adjacent signal. Each conductor allows 5 signal strength. Keep both regions loaded for live two-way signaling; otherwise cached values synchronize upon load. Right-click ascension node or shift-use probe in air, or /fractal ascend.
Inside place a normal stone/copper/log and enter with probe: MESO -> MICRO -> CORE (three nesting levels). Ordinary Minecraft building and redstone work inside. Host destruction invalidates descendants and evacuates occupants on server tick or their next login; rooms remain sealed tombstones and aren't reused. No automatic recovery of stored resources. Host drops one ordinary material (stone -> cobblestone), not a reusable cell. Generated shells/sockets cannot be harvested. Max 256 allocated rooms per save. Use a fresh disposable world. Scale is logical, not a real coordinate-scale transformation or continuous miniaturization. No external miniature render, dynamic mass physics or universal compatibility yet. Runtime test pending.
