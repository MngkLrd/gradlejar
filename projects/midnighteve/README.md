# MIDNIGHT Reborn 0.6.0 — The Festival

Minecraft 1.21.1 NeoForge, Java 21. New-world preset only; back up and create a new world. Six locateable structure types, seven merchant roles, six custom winter biomes and three native fir forms. The Frostmarket and Candle Hall have a Festival Hearth. Right-click with 8 cookies, 3 lanterns, 1 wrapped gift, then 2 wintermarks. Empty hand shows the next requirement. Lamps illuminate progressively. At midnight (17500–18500 ticks), the prepared hearth celebrates once, drops 3 gifts and remains completed. Preparation state is saved as block states; no permanent chunk conversion. If the area is unloaded at midnight, celebration waits until a later midnight while loaded. No crafting or loot for the world-generated hearth/lamp. No external dependency. Original 16px textures; native vanilla models/materials. Actual fireworks are particle and sound effects, not rocket entities.

Build: `python3 generate_reborn.py && gradle --no-daemon clean build`. JAR: `build/libs/midnighteve-0.6.0.jar`. Gradle 9.2.1. Server CI checks templates and the celebration. Client art/gameplay manual QA still required.
