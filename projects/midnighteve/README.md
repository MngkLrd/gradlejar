# MIDNIGHT Reborn 0.8.0 — Winter Tales

Minecraft 1.21.1 NeoForge, Java 21, Gradle 9.2.1. Create a new world with the MIDNIGHT preset. 15 native locateable structure types, seven resident professions, 21 finite personal delivery requests, persistent reputation and a craftable journal. Discover all six regions and all fifteen native structures; sneak-use the journal for exploration progress. Four treasure sites use native loot-table chests. Normal right-click trades; sneak-right-click with an empty main hand asks for a request, and sneak-right-click holding enough of the requested item delivers it. Progress is per player, globally per profession, and copied on death. Festival Hearth remains a shared one-time physical celebration. New craftable gingerbread, cocoa, journal, parcel, ornament, candle cluster, garland and star. Wrapped gifts are now craftable and no longer reward diamonds. Two original synthesized background tracks, six biome-specific local terrain decorations, and client-only aurora ribbons. Disable the aurora for shader troubleshooting with JVM argument -Dmidnighteve.disableAurora=true. Terrain noise and continent shape still use vanilla settings; music and visual quality require client QA.

Build: Python 3 and ffmpeg for authoring only. Run `python3 expand_living.py`, `python3 compose_midnight.py`, `gradle --no-daemon clean build`. JAR: build/libs/midnighteve-0.8.0.jar. No external runtime dependencies.

All new structures are real NBT templates; original six structures remain. Additional landmarks are stargazer_observatory, winter_conservatory, snow_gallery, solstice_shrine. Find structures with /locate structure midnighteve:everlight_hamlet, lantern_fair, mountain_refuge, yuletide_longhouse, icefish_station. Back up saves. New-world visual inspection required. Existing baseline CI server smoke test does not simulate player quests or client rendering.

## Living Winter

Hearthling: custom model, 64x32 atlas, spawn egg, natural spawning, five-minute gingerbread companionship and freezing mitigation. The winter postal itinerary requires visiting the four actual native structures and returning to the postmaster. Physical feast, gift and miniature tree displays are activated in stages. Midnight launches fireworks from unobstructed sky above the square. Client appearance and player interactions require manual QA.
