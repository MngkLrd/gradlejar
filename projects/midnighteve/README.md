# MIDNIGHT Reborn 0.10.0 — Winter Tales

Minecraft 1.21.1 NeoForge, Java 21, Gradle 9.2.1. Create a new world with the MIDNIGHT preset. 16 native locateable structure types, seven resident professions, 21 finite personal delivery requests, persistent reputation and a craftable journal. Discover all six regions and all sixteen native structures; sneak-use the journal for exploration progress. Four treasure sites use native loot-table chests. Normal right-click trades; sneak-right-click with an empty main hand asks for a request, and sneak-right-click holding enough of the requested item delivers it. Progress is per player, globally per profession, and copied on death. Festival Hearth remains a shared one-time physical celebration. New craftable gingerbread, cocoa, journal, parcel, ornament, candle cluster, garland and star. Wrapped gifts are now craftable and no longer reward diamonds. Two original synthesized background tracks, six biome-specific local terrain decorations, and client-only aurora ribbons. Disable the aurora for shader troubleshooting with JVM argument -Dmidnighteve.disableAurora=true. The custom Frostlands density router modifies terrain relief while retaining vanilla continental climate axes, caves and ores; music and visual quality require client QA.

Build: Python 3 and ffmpeg for authoring only. Run `python3 expand_winterfolk.py`, `python3 compose_midnight.py`, `gradle --no-daemon clean build`. JAR: build/libs/midnighteve-0.10.0.jar. No external runtime dependencies.

All new structures are real NBT templates; original six structures remain. Additional landmarks are stargazer_observatory, winter_conservatory, snow_gallery, solstice_shrine. Find structures with /locate structure midnighteve:everlight_hamlet, lantern_fair, mountain_refuge, yuletide_longhouse, icefish_station. Back up saves. New-world visual inspection required. Existing baseline CI server smoke test does not simulate player quests or client rendering.

## Living Winter

Hearthling: custom model, 64x32 atlas, spawn egg, natural spawning, five-minute gingerbread companionship and freezing mitigation. The winter postal itinerary requires visiting the four actual native structures and returning to the postmaster. Physical feast, gift and miniature tree displays are activated in stages. Midnight launches fireworks from unobstructed sky above the square. Client appearance and player interactions require manual QA.

## Frostlands 0.9

New worlds use midnighteve:frostlands noise settings, derived from Minecraft 1.21.1 generated vanilla Overworld settings (pinned in vanilla_overworld_1_21_1.json, reference: https://github.com/misode/mcmeta/tree/1.21.1-data). Continuous terrain masks create glacial coastal cuts, rolling inland terrain and upland ridges. Six native biome surface rules, original froststone and froststone bricks, recipes and tool tags. Four highland structure palettes receive new masonry and supported roofs gain snow. Four revised decorative models have verified 1:1 face UVs, four item sprites and two tiled stone textures are reauthored. Back up saves; create a NEW Frostlands world; existing worlds retain their recorded generator settings. Manual client visual QA and multiple-seed terrain sampling still required.

## Winterfolk 0.10

Snowstag (24 HP, berries lure and breed, wolves avoided) and Snow Grouse (8 HP, seed breeding, persistent egg timer, distinct grouse egg ingredient). Authored non-overlapping 64x64 and 64x32 box-UV skins, separate models and walking animation. Hollycroft Farm is a native 47x24x39 template with a furnished farmhouse, enclosed barn, animal stalls, gates, livestock, crops and compatible resident workstation. Existing resident templates receive additional compatible job sites only where an authored clear area is found. Market Ledger: normal right-click a resident to view the day's request, sneak-right-click to deliver matching items from the inventory. One order per profession per player per day, available during ticks 1000–11000. Vanilla trades and story requests are unchanged. Five new item textures, venison cooking, stew and grouse egg baking. Manual client rendering and player-interaction QA still required. CI checks actual farm geometry, both animal entities and the saved egg timer.
