# MIDNIGHT: The Endless Eve 0.1.0
NeoForge 21.1.262, Minecraft 1.21.1, Java 21.
Full sources are restored from source-b64 during the existing build.yml CI workflow.
This mod converts Overworld biome IDs to snowy_taiga permanently and changes surface snow/ice. Back up your world before using it.
Right-click presents to obtain winter star shards; craft a winter bell (star shards around a bell with gold), use for presents and buffs. Every third midnight brings gifts.
Build via Gradle 9.2.1: gradle --no-daemon clean build. JAR: build/libs/midnighteve-0.1.0.jar.
