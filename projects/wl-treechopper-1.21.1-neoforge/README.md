# WorldLogic TreeChopper 0.4.0 — development candidate
Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21. Four persisted notch depths with matching collision and generated vanilla-textured models, variable axe hits, opposite-face felling advantage, a stump and a 36-tick rigid pivot animation via vanilla block displays. Eight vanilla log types. Initial recognizer is intentionally conservative: straight, isolated single-column trunks with a natural nonpersistent crown; branching/multitrunk/custom Terrarian trees are not supported yet. A placed replica of a natural tree can still be recognized; placement provenance is not tracked. One log is consumed in the stump; upper logs become items, leaves are decorative and do not drop. Animation is kinematic, without swept collision, damage or fallen-log placement. Core/HP/Terrarian API integration is deferred to 0.5.0; optional core metadata allows standalone server regression. No duplicate fatigue counter. NeoForge protocol player backend is unsupported by the shared runner: QA uses the same server left-click event with FakePlayer, operator-only QA command. No client validation or save/reload test claimed.
