# Potion Timer Bar 0.3.1 - fabric 26.3

Client HUD: one 81x5 pixel potion-colored countdown bar. Selects longest remaining active effect. Potion registry palette with harmful red and beneficial light green fallbacks. No status effect means no bar. Config: config/potiontimerbar-client.toml. Java 25, Gradle 9.7.1. Fabric API required. Build: gradle clean build. Release JAR: build/libs/potiontimerbar-fabric-mc26.3-0.3.1.jar.
