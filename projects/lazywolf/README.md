# Lazy Wolf
Minecraft 1.21.1 / NeoForge 21.1.197 / Java 21.

- Tame a vanilla wolf with bones. Only its owner can equip the pack.
- Shift-right-click with Wolf Harness to equip; shift-right-click with an empty hand to remove.
- Right-click a harnessed wolf to open a 9-slot inventory.
- Right-click a wolf while holding the Leash Belt: connect/disconnect to yourself, consuming/returning a lead. Supports up to ten leashed mobs nearby. Put the belt back in your inventory after connecting.
- Inventory persists on the wolf. When a wolf dies, the harness and stored items drop.
- A custom 3D side-satchel layer renders on harnessed wolves.

Items are in the Tools & Utilities creative tab.

Build: gradle clean build
Jar: build/libs/lazywolf-1.21.1-0.1.0.jar
