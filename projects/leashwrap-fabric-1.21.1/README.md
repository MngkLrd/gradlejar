# LeashWrap 1.0.1
Minecraft 1.21.1 / fabric / Java 21.
Hold a vanilla lead attached to a mob, right-click a tree trunk or solid block. Two visible
rope turns and a tied knot render on the full block. Shift+right-click with lead to untie.
Fences retain the vanilla knot.
Source builds with Gradle 8.14.3: `gradle --no-daemon clean build`.
Final JAR: `build/libs/leashwrap-fabric-1.21.1-1.0.1.jar`.
Client and server mod required. Dedicated-server logic is unchanged in this visual update.
