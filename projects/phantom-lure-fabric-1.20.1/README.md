# Phantom Lure Fabric 1.20.1
Original 0.1.1 model, textures and mechanics. Java 17, Gradle 8.14.3.
Build: `gradle --no-daemon clean build`.
Output: `build/libs/phantomlure-fabric-1.20.1-0.1.1.jar`.
Craft: String / Amethyst, Redstone, Amethyst / Ender Pearl, Diamond, Ender Pearl.
Place during day or night, counts down for 12 seconds after nightfall, summons one phantom; insert another diamond for 3-5.
Sleeping cancels. Tagged summons vanish at dawn; no free daylight drops. Test in-game after build.
