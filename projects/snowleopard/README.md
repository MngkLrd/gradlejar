# Snow Leopard

Minecraft 1.21.1 / NeoForge 21.1+ / Java 21.

A snow leopard with a unique animated cubic 3D model, rosette-spotted texture, chunky snow paws, rounded ears, long bushy tail, spawn egg, cod/salmon breeding, and rare natural spawns in snowy mountain biomes.

Build: `gradle --no-daemon clean build`
JAR: `build/libs/snowleopard-1.21.1-1.0.0.jar`
Test: `/summon snowleopard:snow_leopard`, spawn egg creative inventory, frozen peaks / snowy slopes / grove, head and leg motion, baby model, vanilla dedicated server.

Build verification through pull request checks.
