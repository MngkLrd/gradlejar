# Bearback Fabric 1.21
Fabric port of Bearback 0.2.2. Tame polar and black bears, ride with saddle and jump, swipe with R, 3D saddlebags, 18 inventory slots accessible E while riding and Shift+RMB on foot, drops on bear death.

Minimum Fabric Loader 0.17.3. Java 21, Gradle 9.2.1.
Build: `gradle clean build`
Output: `build/libs/bearback-fabric-mc1.21-0.2.2.jar`
