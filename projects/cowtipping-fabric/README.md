# Cow Tipping 1.0.0
Minecraft 1.21.1, Java 21.

Right click an adult vanilla cow with an empty main hand to tip it over. The cow lies down for a few seconds before rising. Nearby cows approach and watch. No damage.

This project is built by the Minecraft Mod Build Hub in MngkLrd/gradlejar.

Gradle: gradle --no-daemon clean build
Output: build/libs/cowtipping-LOADER-1.21.1-1.0.0.jar

Test on client and dedicated server. Install the same mod on both client and server for multiplayer visual sync. No Fabric API required.
