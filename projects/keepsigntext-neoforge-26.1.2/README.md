# Keep Sign Text 1.0.0 (26.1.2, neoforge)

Break a vanilla sign with any text on either side; the dropped sign must retain text, glow, color and wax when placed again. Supports hanging signs.

Build with the Gradle version and Java toolchain in build-profile.json. Test creative and survival, waxed and unwaxed, glowing and dyed, both front and back, world reload, and dedicated server.

This revision adapts to vanilla item component changes in 26.x; production releases contain only built JAR files.

Release integration check r3: verify survival block drop and re-placement.

Release validation r4: explicit generic type for 26.x BLOCK_ENTITY_DATA.
