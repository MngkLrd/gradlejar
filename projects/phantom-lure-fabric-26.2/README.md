# Phantom Lure Fabric 26.2
Original 0.1.1 textures and model are reused exactly.
Java 25; Gradle 9.5.1.
Build: `gradle --no-daemon clean build`.
Output: `build/libs/phantomlure-fabric-26.2-0.1.1.jar`.
Place lure any time; countdown at night (240 ticks). Uncharged summons one phantom, insert another diamond for 3-5. Sleeping cancels the lure; custom summoned phantoms vanish before dawn. No natural phantoms are modified.
Craft: String / Amethyst, Redstone, Amethyst / Ender Pearl, Diamond, Ender Pearl.
Test world loading, crafting display, charged model, survival refunds, nighttime summon and sleep/dawn cleanup.
