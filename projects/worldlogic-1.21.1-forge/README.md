# World Logic 0.1.1-alpha
Minecraft 1.21.1 • Forge 52.1.0 • Java 21 • Gradle 8.10.2 • official mappings.
Run gradle --no-daemon clean build; output build/libs/worldlogic-forge-mc1.21.1-0.1.1-alpha.jar.
Config: config/worldlogic.properties; restart after editing. Install on both sides during tests. One added spoiled food item; no added blocks or dependencies. Burning Arrows excluded.

## Scope / limitations
Experimental implementation, not complete design. Events and bounded local samples; no world-wide scans. Destructive rules default off. Tag-driven defaults; tags can be extended by datapacks. Test on backups. No claim of client or server gameplay verification.
Implemented first-pass: gravel slumping, dripstone projectile detachment, fragile pots/lanterns, blast glass, knockback mass, projectile damage adjustment, shield momentum, creeper impulse, cactus impact, landing recovery/soft landing, tool streak, cobweb resistance, grip, sprint fatigue, armor visibility, breath debt, exertion, cold shock, wet bow, current weighting, extinguish, wet friction approximation, mud particles, snow layer compression approximation, rain droplets, storm projectile drift, campfire sparks/heat/thermal shock, simple smoke and enclosed-fire heuristic, explosion ash, crop crowding/flood stress, food scent, herd panic, one-shot hot meal bonus after smelting, heavy items, bounded shared air pocket heuristic.
Added in second pass: shallow-angle stone/metal ricochet for non-piercing vanilla arrows (replacement entity preserves serialized data); optional hard-impact arrow loss; door closing push, optional falling sand/gravel damage and dropped wet food spoilage; hot meal timestamp on smelting event output; campfire/smoker scent. Third pass: optional weighted and stone plate mass via vanilla calculation mixins, conservative opt-in tree crown decay, snow shedding, bounded ventilation search. Not implemented: real torch light extinction (smoke only), persistent pocket oxygen, true smoke fluid simulation or snow layer falling entities. Tree detection is heuristic and placed-log tracking is session-only; off by default. Redstone changes off by default to protect existing contraptions. Mud is particles rather than decals. Finite air only tests air cells adjacent to water below sea level; oxygen state is ephemeral. Hot meal timestamp is applied to the Forge smelting output event; campfire outputs and automated extraction still need coverage.
QA: runClient and runServer; check break/drop counts, mobGriefing=false, claim mods, ricochet angles and arrows not duplicating, water breathing, air pockets shared, player logout/rejoin, rain and projectiles, multiplayer movement corrections, large farms, config disabled rules. Profile crowded areas.
