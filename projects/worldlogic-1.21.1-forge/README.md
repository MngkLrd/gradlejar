# World Logic 0.1.0-alpha
Minecraft 1.21.1 • Forge 52.1.0 • Java 21 • Gradle 8.10.2 • official mappings.
Run gradle --no-daemon clean build; output build/libs/worldlogic-forge-mc1.21.1-0.1.0-alpha.jar.
Config: config/worldlogic.properties; restart after editing. Install on both sides during tests. No added blocks/items or dependencies. Burning Arrows excluded.

## Scope / limitations
Experimental implementation, not complete design. Events and bounded local samples; no world-wide scans. Destructive rules default off. Tag-driven defaults; tags can be extended by datapacks. Test on backups. No claim of client or server gameplay verification.
Implemented first-pass: gravel slumping, dripstone projectile detachment, fragile pots/lanterns, blast glass, knockback mass, projectile damage adjustment, shield momentum, creeper impulse, cactus impact, landing recovery/soft landing, tool streak, cobweb resistance, grip, sprint fatigue, armor visibility, breath debt, exertion, cold shock, wet bow, current weighting, extinguish, wet friction approximation, mud particles, snow layer compression approximation, rain droplets, storm projectile drift, campfire sparks/heat/thermal shock, simple smoke and enclosed-fire heuristic, explosion ash, crop crowding/flood stress, food scent, herd panic, one-shot hot meal bonus after smelting, heavy items, bounded shared air pocket heuristic.
Not implemented: material ricochet, arrow recovery, tree decay, falling-object extension, exact redstone mass, door movement, item spoilage, real torch light extinction, per-stack hot meal timestamps, cooking scent, persistent pocket oxygen, snow weight damage, genuine draft simulation or ventilation pathfinding. Some placeholders in config are reserved and should not be treated as implemented. Mud is particles rather than decals. Finite air only tests air cells adjacent to water below sea level; oxygen state is ephemeral. Hot meal bonus tracks smelter player, not stack.
QA: runClient and runServer; check break/drop counts, mobGriefing=false, claim mods, ricochet NOT expected, water breathing, air pockets shared, player logout/rejoin, rain and projectiles, multiplayer movement corrections, large farms, config disabled rules. Profile crowded areas.
