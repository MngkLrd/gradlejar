# Timberfall 0.1.0
Minecraft 26.3, NeoForge 26.3.0.90, Java 25. Experimental build.
With an axe, right-click an upright log three times to carve a progressively deeper 3D notch, then right-click again to topple the tree toward the player facing direction.
Trees must be 3–23 blocks tall, natural-looking vertical single trunks. No player damage or building destruction. Giant 2x2 trunks and modded wood are not yet supported.
Includes modeled notches for 12 wood variants and a synchronized animated falling-tree entity.
Build with `gradle --no-daemon clean build`, output `build/libs/timberfall-0.1.0.jar`.
Test singleplayer, multiplayer, and dedicated server before distribution. Gameplay not yet validated.
