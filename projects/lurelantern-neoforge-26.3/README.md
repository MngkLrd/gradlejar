# Lure Lantern 1.3.10, NeoForge 26.3 (experimental port)
Java 25 / Gradle 9.7.1. Recipes migrated to string ingredients, custom data to ValueInput/ValueOutput. Server capture, modes, NBT and release reimplemented.

**Current limitation:** Dynamic miniature of captured creature in the item/world is not ported to 26.3's client renderer yet. This is a compilation candidate, not a feature-complete release.

Build: `gradle clean build`, output `build/libs/lurelantern-neoforge-mc26.3-1.3.10.jar`.
