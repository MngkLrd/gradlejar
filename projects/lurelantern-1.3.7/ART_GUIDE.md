# Lure Lantern 1.3.4 Artwork

Source: https://blockbench.net/wiki/guides/minecraft-style-guide/

Four **native 16x16** PNGs. No repeated animation strips. Reuses vanilla lantern and hanging lantern models; maintains existing model UV, item display transforms, item model IDs and blockstates.

Artwork: constrained palette (iron and one glass ramp per state), 2-3 connected areas of shadow/highlight around structural features, consistent top-left highlight, darker lower-right edges. No smooth gradients, pillow shading, random noise, dither, antialias, mixels or high contrast neon. The basic lantern is opaque; both advanced texture variants have alpha in their middle pane.

**Important**: Gameplay Java classes are identical to 1.3.3. The original 1.3.2 classes are retained via SHA-256 verified repackaging. Test in Minecraft for behavioral validation.
