# Lure Lantern 1.3.8 | NeoForge 1.21.1

User-test follow-up to v1.3.7. Matches the mining selection outline to the full model height, changes survival break hardness to 0.8 and preserves captured-mob NBT drops. Advanced first-person rendering will be corrected with independent metal/entity/glass passes. Basic Lure Lantern will have matching Advanced geometry with violet glass.

Build with Java 21, Gradle 9.2.1 and NeoForge 21.1.262: `gradle clean build`. JAR: `build/libs/lurelantern-1.3.8.jar`. Server tests: `gradle runGameTestServer`.
