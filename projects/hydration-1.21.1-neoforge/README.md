# WL: Hydration 0.4.0 development candidate
Empty main/off hand: right click water to drink 250 mL. Vessel in main hand: aim at a source and right click to fill in one action; otherwise hold right click to drink 250 mL. Sneak-right click with another vessel in offhand to transfer main to offhand up to capacity. Sneak-right click with charcoal filter offhand treats up to 3 L, consuming one filter. Sneak-right click lit campfire with heatproof vessel to boil; offhand copper condenser selects distillation. Stay within four blocks and keep vessel unchanged in main hand; interrupted treatment produces no output. Boiling evaporates 5%, preserves modeled salt, distillation yields 70% with removed brine abstracted as waste. Composite contamination risk, not separate real pathogens and sediment. All numbers are gameplay tuning. No actual placed vessel or Fluid API bridge yet. RC28 API baseline; RC29+ native sources not independently tested. Existing Temperature and Trauma optional bridges retained. Dedicated creative tab. No release without production QA; current shared CI needs pinned Core JAR dependency. Visual QA required for custom pixel assets.

0.4.0: clay basin 3 L, barrel 16 L, rain collector 8 L, stationary filter 6 L, intake 1 L, directional clay pipe. Tanks store WaterBatch in block entity; breaking spills water and drops empty block, no duplicated contents. Right-click with vessel withdraws; sneak right-click deposits; empty hand shows status, sneak drinks. Rain uses Core atmosphere and actual sky exposure; snow doesn't collect. Intake draws a source immediately above it, without removing the world fluid block, as an explicit inexhaustible source abstraction. Directional pipes use the attachment face as inlet and look direction as outlet; matching neighboring inlet/outlet required, elbows rendered as two arms, no uphill flow, maximum 24 pipe blocks per route, lower destination required; redstone blocks flow. Transfer max 250 mL/source/second; no pumps, no finite lake depletion, no pipe fluid storage, no Forge capability bridge. Filter cartridge has 12 L throughput, accepts up to 24 L remaining charge and only treats actual output; no cartridge no output. Models use existing vanilla material textures and 3 coarse fill stages (custom opaque pixel water surface), no graphical claim.
