# Sleep Debt 3.0 manual game tests

1. Install NeoForge 1.21.1 with Java 21 and ONLY Sleep Debt. Game must load without JEI/EMI/Jade/Patchouli/Accessories.
2. Repeat with JEI alone, EMI alone, Jade, Patchouli, Accessories, and all of them.
3. Run a dedicated server; ensure no Minecraft.client classes are accessed on server.
4. Create a world in 2.6, backup it, upgrade to 3.0. Verify existing fields/items/blocks and persistent debt survived.
5. `/sleepdebt debug set 800 800 600`. Mine, attack and sprint. Verify fatigue and stress change and sync.
6. Test bedroll rest at night and by day, standing still seven seconds.
7. Walk away or take damage mid-rest. Session should cancel without giving rewards or applying cooldown.
8. Repeat rest immediately: cooldown applies. Log out while resting and log in: no lingering sessions.
9. Rest exposed in rain versus sheltered, in cold biome, near hostiles, near dreamcatcher/incense, with pillow/mask. Compare quality.
10. Open Sleep Journal: three bars, previous sleep report and forecast for current location. Check RU and EN at GUI scales 2, 3, 4.
11. Test partial bed sleep spam. Repeated full sleeps within 6000 ticks should have recovery capped to 90.
12. Test default vanilla phantoms at debt <250: none from vanilla attempt.
13. Test debt >=850 without nearby dreamcatcher. Vanilla spawn amount may increase by one, but vanilla rules still apply.
14. Test protected camp with dreamcatcher: vanilla phantom attempts denied.
15. Disable phantom integration via server TOML and retest vanilla behavior.
16. Test at low light at debt 800+: MiragePlayers world-space hallucinations are client-only and do not affect hitboxes.
17. Check coffee maker GUI scale/UV and break-drop behavior; crop ages and recipes.
18. Inspect texture seams, item readability, navigation, vanilla font and performance near many mobs.
19. Run `gradle clean build`, inspect validation output and release checksum.

Known limits: no automated in-game launch in CI. Alpha is NOT release-grade yet.
