# Harvest Glow v1.1.0 — 26.2 fabric
Client-only mod. The H key toggles crop highlighting.
Nearest mature plants get rotating green particles and occasional subtle white sparkle.
Settings: config/harvestglow.properties (generated on first launch).
No blocks, items, recipes, registries or networking. Fabric requires Fabric API.
Java 25; Gradle 9.5.1. Build: gradle --no-daemon clean build
Jar: build/libs/harvestglow-fabric-mc26.2-1.1.0.jar
