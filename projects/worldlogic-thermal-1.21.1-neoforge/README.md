### Public room API (ROOM_API_VERSION = 1)
`dev.minemods.thermal.api.ThermalApi.roomClimate(ServerLevel, BlockPos)` and `roomClimate(ServerPlayer)` return `Optional<RoomReading>` on the server thread. `RoomReading`: indoor (true for successful query), airC and massC (°C), humidity (relative %, 0..100), ventilation (modeled index, 0..1), volume (interior cells). Coordinate queries work in loaded rooms without a player and share the same per-second simulation. Empty outdoors, unrecognized rooms or missing authoritative Core air; no chunk loading, no setters, no fabricated room temperature. Player query checks the current position. Legacy API_VERSION=1 and status(ServerPlayer) remain unchanged. Other addons should use the result for local climate only, falling back to their existing Core outdoors contract, and avoid bulk querying every block each tick.
