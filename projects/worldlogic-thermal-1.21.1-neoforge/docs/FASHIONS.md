# Thermal garment and item art
Project-local notes created for 0.7.0; no original FASHIONS.md found in the repository trees. Authority: repository AGENTS.md Minecraft visual style section, docs/VISUAL-QA.md and https://blockbench.net/wiki/guides/minecraft-style-guide/.
- 22 new hand-authored 16x16 sprites: deliberate silhouettes, restricted material color ramps, opaque pixels, top-left highlights, no interpolation. Clothing uses tinted vanilla leather geometry on player (not custom wearable mesh). Warm items use ochre/brown material tones, cooler items restrained pale blue/linen. The charge bar itself is runtime UI: red-orange/yellow for heat, dark blue through cyan for cold. The charge bar is deliberately smooth as requested, not a smoothed item texture.
- Fourteen placeable device and textile models use simple cuboids and vanilla material references with explicit face UV dimensions. No copied vanilla image files. Model states indicate active/ready/closed.
