# Bearback 0.1.2 — Minecraft 26.3 NeoForge

Port of Bearback 1.21.1 to Minecraft 26.3 using modern entity render states and render-graph based saddle rendering. Keeps black bear on polar bear silhouette, same charcoal fur/cream chest, and identical saddle dimensions, fish taming, owner defense/follow, riding and R paw attack.

Build at NeoForge 26.3.0.76 (first stable release) using Java 25 and Gradle 9.2.1:
`gradle clean build` -> `build/libs/bearback-26.3-0.1.2.jar`.

No dependency on Rideable Polar Bears. Minimum accepted NeoForge: 26.3.0.76.
