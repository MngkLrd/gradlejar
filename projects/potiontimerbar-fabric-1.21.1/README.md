# Potion Timer Bar 0.3.1 - fabric 1.21.1

Client HUD: one 81x5 pixel potion-colored countdown bar. Selects longest remaining active effect. Potion registry palette with harmful red and beneficial light green fallbacks. No status effect means no bar. Config: config/potiontimerbar-client.toml. Java 21, Gradle 8.14.3. Fabric API required. Build: gradle clean build. Release JAR: build/libs/potiontimerbar-fabric-mc1.21.1-0.3.1.jar.
