# WorldLogic: Structures 0.1.0 (development)
Minecraft 1.21.1 NeoForge; Core 1.3.0 / RC55 API revision 16. Core source baseline 266eebbfed193673b027da6243b20d728da99ae1.
Public entrypoint `dev.minemods.worldlogicstructures.api.StructuresApi`.
`WorldLogicCapabilities.find(StructuresApi.KEY, 0)` returns immutable catalogue v1 revision 0; `designs()` returns stable design IDs with geometric parameters, and `family(WorldgenEnvironment)` selects the exact same architectural family used by native generation. No world mutation, loading, live weather, or simulated climate duplication. Unknown, marine and subterranean samples return empty. `Family.locateId()` returns the native registry ID; use vanilla `/locate structure worldlogic_structures:cold` etc. or `/locate structure #worldlogic_structures:abandoned`. Core command alias `/worldlogic structure_find [cold|boreal|temperate|arid|tropical|wetland|alpine|coast]` delegates directly to the native locate command, without modifying Core or raising permissions. No global custom search cache; normal world generation and structure starts are authoritative.
Structure piece saves stable design ID, origin, rotation and wear seed. No retro-generation, loot containers, spawners or entities. New chunks only. Spacing data pack: 24 chunks, separation 9. Native placement rejects incompatible Core presets and unsuitable sites, so spacing is an attempt interval, not a guarantee of encounter distance.
RC55 production QA is not yet eligible; exact required Core artifact and combined production-world evidence are outstanding. Never claim a verified release from this source candidate.

Operator QA: `/worldlogic_structures selftest` checks the actual catalogue/rotations, native registry and capability. `/worldlogic_structures starts` uses the real registered Core preset, two fixed seeds, native random-spread candidates, actual structure generation, wrong-climate and biome-negative controls. This does not establish block placement or graphical QA. The existing compatibility pack `worldlogic-structures` builds the two exact source projects and runs their scenarios together; no new CI workflow.
