# Lure Lantern Fabric 1.21.1 (port prototype)
Java 21, Fabric Loader 0.17.3, Fabric API 0.116.17. Original 1.3.10 models, translations and textures preserved, separate Fabric client renderer. Advanced lantern mining uses a Fabric after-break drop hook with a zero-loot-table to prevent duplication. Build: gradle clean build.
