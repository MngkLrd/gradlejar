# WorldLogic: Metabolism 0.1.0 development candidate
Minecraft 1.21.1 NeoForge; Core RC33 client tabs API. Server-authoritative persisted food uptake, ten nutritional adequacy indices, digestion, fast/fat energy pools, toxin clearance, Core fatigue readout and low-energy exertion. Optional read-only Trauma anatomical health via public status API. No dairy group, no heart conversion. Five localized tabs with vanilla item icons and hover explanations. Generic unknown foods grant estimated energy only, not invented micronutrients. Values are game-calibrated. No automatic Trauma healing, disease mutation, hydration or Temperature writes; public physiology multipliers are for subsequent integration. Adaptive six-axis nutrient radar on wider screens; no trend history or custom art in this first code iteration. GUI/client and network food consumption not tested. Requires exact Core+Metabolism joint runtime evidence; ordinary single-JAR server run without required Core cannot validate this candidate. No release claim.
