## 0.9.0 — energy and eating rework
Core remains sole authority for 0–100 stamina. Public API fatigue/recoverExertion used, no Core edits. Food instantly transfers a bounded carbohydrate-dependent part of its calories out of the digestion queue (no duplicate kcal), then adds up to 8 actual stamina points; ongoing digestion up to 1.8 points/s at rest and 40% during movement. Core's normal rest recovery is untouched. Stomach capacity remains 1800 kcal proxy; above ~78% overload can accumulate and reduce digestion/absorption, overflow discarded, no full-stomach food bonus. Full vanilla hunger no longer blocks eating with stomach space; native vanilla permissive paths retained. Cake bites handled after successful vanilla action, milk recognized independently of FOOD. Modded FOOD values use known profiles or nutrition/saturation estimate; nonstandard food providers use reportFoodIntake only for actual completed portions not already handled by FOOD/cake. Vanilla water potion and actual container volume delta (Hydration public liquidWater snapshot) give up to 3 stamina points, 250 mB clean = 2, 15 active seconds cooldown; no calories, no extra Hydration balance or inferred intake. Direct source/tank and other non-item drinks require Hydration provider callback (issue #257). No other addon source changes. Persistence schema 4 migrates old states; payload 5 requires matching clients. API v1 rev4 adds energy() snapshot, reportFoodIntake() and reportWaterIntake() validated server-only contracts. Core RC22 exact QA pin preserved; newer Core runtime and real pack/GUI tests separate. Game balance values not clinical quantities. No custom textures.
