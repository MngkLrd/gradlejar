# WorldLogic: Aquaculture 0.1.0 development candidate
Minecraft 1.21.1 / NeoForge / Java 21. Requires Core RC37. 36 registered species, independent type IDs, raw catch IDs, persistent individual mass, length, age, sex, and bilingual tooltips. Bounded loaded-water spawning samples Core waterProfile and environment. Temperature is an air-derived approximation; habitat parameters are game-tuned, not a validated biological dataset. No worldgen changes.
Visual scope: initial vanilla cod mesh and texture reused with species-specific proportions. Unique meshes/UV textures, swimming animation and actual native-water swimming need follow-up and graphical QA. Do not describe this candidate as completed 0.1.0. Bucket transport deliberately blocked to avoid losing species identity. Raw catch not yet edible; processing and nutrition are later modules. Natural spawning, actual death drops and persistence across server restarts require additional runtime tests; current command exercises registered entity creation, trait serialization to catch item and habitat positive/negative controls. No population ledger, fishing hook integration, migration or reproduction yet.
Build with shared Gradle Build Hub; no release eligibility until actual checks pass.

Feeding iteration: per-species food tags, consumption, digestion cooldown and persistent satiety. Species registry contains nursery, maturity and incubation parameters for future population-backed roe. See REPRODUCTION.md. No live mating or hatching yet. Previous Build Hub run 46049355636 reached QA-2 but failed dedicated server startup because Core RC37 was absent from the QA runtime. Exact matching standalone Core is required; do not make Core optional or shade it.
