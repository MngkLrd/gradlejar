# Fragile Glass 1.0.1
Minecraft 1.21.1, fabric, Java 21. Build with Gradle 8.14.3: gradle clean build.
Output: build/libs/fragileglass-fabric-mc1.21.1-1.0.1.jar.
Test: one-click glass; Silk Touch; arrows and tridents; snowballs and eggs against panes; hard landings; permission checks. Fabric uses vanilla permission checks, not Forge claim events. No runtime tests performed.

Vanilla glass identification is independent of optional Fabric data tags. Required production-server and localhost network-player regression tests.
