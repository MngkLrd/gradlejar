# Screenshot Manager 0.10.0 - Film & Lens
Minecraft 1.21.1, NeoForge, Java 21; client-only. All 0.7 capture tools retained.
Tools grouped into Navigate, Draw, Privacy and Focus. Tools panel switches between settings and color/style; RGB controls and eyedropper. B brush, E eraser, T text, C crop, I eyedropper, V pan. Ctrl+V imports a clipboard image. Layers supports duplicate. File supports canvas presets, Save Project and Load / recover (latest autosaved committed edits in separate .smrecovery; manual project preserved). Title styles and rotation are editable.
Color panel: use < / > to select Basic, Tone, Cinematic, HSL (HSV-based hue/saturation/light), Color wheels (warmth/tint), Tilt Shift, Clarity / Dehaze and Gradient. Move sliders for asynchronous 768px preview; Apply commits full resolution, Cancel discards preview; switching mode discards preview. Tilt Shift includes Miniature and Diagonal presets, focus position, band width, angle, blur, feather and saturation.
File > Thumbnail Studio: six fixed aspect/dimension presets, four layouts, title/subtitle, color, size, position, composition guides, live preview. Export PNG or Open in Studio (flattened PNG). Library > Manage: images, GIF files (open externally), trash/restore and rename; sidecars moved with media, favorites and albums migrated. Existing collage and album tools preserved.
Capture: O editor, P library, F4 depth, F6 GIF, F7 burst, F8 copy capture, F9 photo, F10 clean. J/L/H flyby. U entity cutout. G toggles Ghost Shot overlay of latest shot; F10 captures without overlay. R in photo mode rotates camera in 5 degree steps (Shift+R reverse). I captures six faces and stitches a 2:1 panorama; stand still. F12 experimental 2x framebuffer capture (max 16 MP, disabled with Iris installed). Capture tools save in screenshots/edited. Panoramas are not time-frozen, dynamic objects and shader effects can cause seams. Actual world rendering, camera roll, panorama, high-resolution and shaders require in-game testing. No additional mods required.
Gradle 9.2.1, gradle --no-daemon clean build. Mandatory core smoke tests exercise image effects, persistence, thumbnail dimensions, panorama projection, file bundle operations and prior features.

0.9: Color > RGB curves: drag nine fixed-input points, independently for RGB/master and R/G/B, histogram behind curve. 3-way wheels: choose Shadows / Midtones / Lights and drag the wheel; luminance slider. Perspective: horizontal/vertical projective correction; transparent outside source. Layers > Blend / opacity: Normal, Multiply, Screen, Overlay, Soft Light, Hard Light, Add, Darken, Lighten, Difference; opacity and preview, Apply/Cancel. Geometry, eraser masks and opaque redaction are protected. Tools > Color/style: HEX input (Set/Enter), installed OS font families, Regular/Bold/Italic/Bold Italic. Compare: draggable split with geometry-aligned original; Ctrl+Shift+S still exports side-by-side. Tab hides panels; drag right panel edge to resize. Project v2 reads v1 sidecars; older versions cannot read new sidecars. Actual GUI and graphics QA required.

0.10: Color > Film styles (VHS, CRT, 35mm, Super 8, noir, instant film, night vision, cyberpunk) and Photo presets (landscape, architecture, street, portrait, product, golden hour, night, documentary). Adjustable strength, grain, distortion, texture, vignette; preview and non-destructive layers. Photo mode F9 then N cycles actual FOV presets; Shift+N reverses, existing FOV restored on exit. Lens/aperture hints are real-camera references, not Minecraft optical settings. Tilt Shift now uses multiple blur radii, independent foreground/background, on-canvas guides and Miniature preset; legacy tilt layers still render the old algorithm. This is image-space focus, not optical or depth-buffer simulation. Cinematic bars now 0–25% per edge, old values keep appearance. GIF Studio unchanged. Sources for photography references: Nikon Understanding Focal Length and Understanding Maximum Aperture; Adobe Photoshop Blur Gallery Tilt-Shift. Build Gradle 9.2.1. Runtime GUI QA required.
