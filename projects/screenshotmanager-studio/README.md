# Screenshot Manager 0.7.0 — Pro Photo / Editor UX
Minecraft 1.21.1 / NeoForge / Java 21. Client only. No extra dependencies.
O editor, P library, K copy, F4 experimental depth screenshot, F6 GIF, F7 burst, F8 copy capture, F9 photo, F10 clean capture; J / L / Shift+L / H cinematic flyby.
Studio: drag slider thumbs or click tracks; right-click resets. Color tab cycles Basic, Tone / Curves, Cinematic. Add layer applies settings; selected adjustment layers may be changed with Apply style in Layers. Scroll lists to access all controls. Tone includes shadows, midtones, highlights, levels, gamma, RGB and channel curve controls, saturation and vibrance. Cinematic effects include bloom, grain, color fringe, vignette, sharpen, atmospheric tint and letterbox. Focus blur and shade are image-space effects. F4 captures a HUD-free screenshot with a sampled main-render-target depth map when available; Depth focus tool selects focal depth by clicking a pixel. Add it before geometry operations. Iris and shaderpack depth alignment is experimental, uniform/unavailable maps are rejected.
Pen and Marker are continuous strokes; Highlight keeps rectangle mode. Eraser masks prior drawing/annotation layers in the current geometry stage; it deliberately does not erase privacy redactions or original pixels. Text: click image, type, Enter commits, Escape cancels. Undo all requires a second click and can be undone. Glass toggles translucent UI, Peek hides screenshot to see world, X closes. Game remains unpaused.
Image layers: put PNG/JPG in screenshots/imports. File > Pick import cycles files, Add image inserts centered layer. Select it in Layers; drag on canvas to move, Tools exposes scale, angle, opacity and Apply transform. Embedded PNG layers capped at 768px / 1.5 MB; project capped at 8 MB. Existing sidecars remain readable. World capture saves local scene metadata beside newly taken screenshots, File > Scene info reads it. No teleportation.
Build: gradle --no-daemon clean build, Gradle 9.2.1. In-game QA required. U captures the targeted visible living entity using a separate two-pass GUI model render. Produces transparent PNG and a white outlined sticker in screenshots/edited; these appear in File > Pick import. This is a model portrait, not a mask of the entity in an existing world screenshot; runtime shader QA required. High resolution and 360 panorama are not implemented in this build.
