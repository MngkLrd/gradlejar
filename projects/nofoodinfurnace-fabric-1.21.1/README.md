# No Food in Furnace 1.1.0 (1.21.1, fabric)
Blocks edible smelting in ordinary furnaces only. Includes food components, FOOD-category recipes, and food outputs from modded recipes. Smokers and campfires still work.
The normal furnace shows a red X using the vanilla anvil error sprite, while ore smelting remains unchanged.
Build: Java 21, Gradle 8.14.3; `gradle --no-daemon clean build`.
Artifact: build/libs/nofoodinfurnace-fabric-1.21.1-1.1.0.jar
