# Christmas UI 0.2.0
Minecraft 1.21.1 NeoForge, Java 21, Gradle 9.2.1. Build: pip install Pillow; gradle clean build resourcePack. Client only. New winter cubemap, inventory/creative atlas treatment, all heart variants, join arrows, individual button snow in mod, title flakes. Standalone resource pack has static button states, not per-button snow. Music downloads at build time from Wikimedia Commons; if unavailable, build logs flag omission. In-game and visual QA pending. Enable Christmas UI resource pack explicitly if another resource pack overrides the mod assets.
