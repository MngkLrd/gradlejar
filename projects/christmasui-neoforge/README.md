# Christmas UI 0.1.0
Minecraft 1.21.1, NeoForge, Java 21. Client side. Build with Python 3 + Pillow and Gradle 9.2.1: gradle clean build resourcePack. Art generator downloads the official 1.21.1 client for original GUI geometry and verifies SHA-1. The separate pack contains static assets only. Buttons, hotbar, XP and food use bespoke pixel clusters; vanilla container and secondary GUI assets retain geometry with a palette pass. Title snowfall is cosmetic. No custom sounds, new panorama, custom screens or gameplay changes yet. Test title screen, GUI scales, all button states, slots, health/food/experience HUD, server connection and resource reload in game.
