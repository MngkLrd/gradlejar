# Christmas UI 0.3.2
Minecraft 1.21.1 NeoForge, Java 21, Gradle 9.2.1. Includes 0.3.1 snowy panorama and separate Christmas music pools. Main menu: Jingle Bells (Calm) only. Overworld, creative, underwater and biome-specific game events: five equally weighted instrumental Christmas tracks. Uses vanilla music timing, volume and selection (random selection may repeat). Nether, End, boss and record sounds unchanged. Required audio downloads are validated as unique Vorbis recordings; credits included. Build: pip install Pillow; gradle clean build. In-game QA pending.
